Mac Operator

Atlas can operate only the dedicated Atlas Inbox folder. It cannot reach the rest of Documents, Desktop, hidden files, executables, or the terminal through this task family.

Immediate stop: turn off Allow agent tools, stop Atlas, or double-click Pause Atlas Mac Operator.command.

Native Phone Companion

The first phone gate reports only device, operating-system, app, and battery status through an explicitly paired, on-demand local bridge.

It does not request Contacts, Calendars, Photos, Microphone, Camera, Location, Bluetooth, Notifications, or background access. Immediate stop: disconnect in the app, stop the separate bridge terminal, or double-click Pause Atlas Phone Companion.command.
